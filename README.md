# Systems Lab

An implementation-heavy, first-principles study of computer systems.

The sequence is deliberate:

1. Database internals
2. Networking
3. Operating systems
4. Distributed systems
5. Compilers and runtimes

For each topic, the loop is: read the theory, implement the mechanism, break it deliberately, benchmark it, and compare the result with production systems. The goal is durable understanding earned through working code, controlled experiments, and honest notes—not passive completion of a reading list.

The `curriculum/` directory contains the study plan. Implementations live in the corresponding topic directories; `notes/`, `papers/`, and `experiments/` hold supporting material.

This repository intentionally starts without a framework, build system, CI, or language-specific tooling. Those choices should emerge from the work.
